# Invitación · Asociación de Luriguayos Revelación Fanáticos Juli

Invitación web (pensada para celular) a la recepción de la asociación.

**Ver en línea:** https://aryancito.github.io/luriguayos/

- `index.html` — la invitación (sobre, danzantes animados, datos, mapa, música).
- `taller.html` — taller para probar colores del traje.
- Datos del evento: bloque `EVENTO` al inicio de `invitacion.js`.
